Abschlussprojekt

Kurzbeschreibung:

Abschlussprojekt – B & A Archery Club Entwicklung einer responsiven Website für einen fiktiven Bogensportverein mit Vue 3, JavaScript, CSS und Vue Router. Die Anwendung bietet eine mobile Navigation, verschiedene Informationsseiten, eine interaktive Bildergalerie mit Lightbox sowie ein Demo-Kontaktformular. Besonderer Fokus lag auf einer übersichtlichen Benutzeroberfläche, wiederverwendbaren Komponenten und der Darstellung auf unterschiedlichen Bildschirmgrößen..

Hangman-Spiel

Kurzbeschreibung:

Ein interaktives Worträtsel, entwickelt mit HTML, CSS und JavaScript. Spieler erraten zufällig ausgewählte Hauptstädte, bevor zehn Fehlversuche erreicht sind. Das Spiel bietet eine interaktive Buchstabentastatur, eine Gewinn- und Verlustanzeige sowie ein responsives Design für Smartphones, Tablets und Desktop.
Technologien: HTML5 · CSS3 · JavaScript (Vanilla JS)

Android-Einkaufsliste

Kurzbeschreibung:

Eine native Android-App zur Verwaltung einer persönlichen Einkaufsliste, entwickelt mit Java und XML. Artikel können hinzugefügt, als erledigt oder nicht verfügbar markiert und gelöscht werden. Eine Autovervollständigung erleichtert die Eingabe. Dank SharedPreferences und JSON bleiben die Einkaufsliste und ihre Statusinformationen auch nach einem Neustart erhalten.
